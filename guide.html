How to Use The Dice Vault Action Roller

Build a reusable list of dice-based actions, keep actions grouped by character or enemy, and roll them when you need them. This guide explains the roller's inputs, level scaling, results, and how to keep a backup of your collection.

1. Create an action from its dice formula

Give the action a name, then enter the number of dice and the number of sides on each die. For example, an action written as 2d8 + 3 uses two eight-sided dice and a flat modifier of 3. Enter 2 for the number of dice, 8 for die sides, and 3 for Modifier. The modifier is optional; use a negative whole number for a penalty.

The roller accepts any positive whole-number dice count and side count. It does not decide whether a formula is allowed by a particular game, character feature, or table ruling. Check the values against the rules your group is using before saving an action.

Example: for 2d8 + 3, the roller displays both die results and adds them together with 3. If the dice show 4 and 7, the total is 14.

2. Organize actions by character or enemy

In the “Link to” menu, choose Character or Enemy and enter a name. The action list groups saved entries by that name, so similarly named actions remain easy to find during a session. Choose “No character or enemy” when an action should stay unassigned. Use the All, Characters, Enemies, and Unassigned filters to narrow the list; each filter shows how many saved actions match it.

Use the edit control on an action card to change its formula or assignment. Delete removes just that action. “Clear all” removes the full collection after confirmation.

3. Set up an action that scales by level

Turn on “Scales when used at a higher level” to set a base level and an amount of extra dice added for each level above it. When you roll, choose the action's use level; it can be any whole-number level from the base level through 20. The roller adds the extra dice once for each level above the base.

Example: a base of 1d8 at level 1 with 1d6 added per level rolls 1d8 at level 1, 1d8 + 1d6 at level 2, and 1d8 + 2d6 at level 3. Set the base and scaling dice to match the progression your group wants to track.

4. Roll an action or a d20 check

Select Roll on an action card to see each dice group, the individual die results, and the final total with its modifier. The separate “Roll to hit” control rolls one d20 and adds the whole-number Hit Mod value. A natural 20 is labeled as a critical hit, but the roller does not apply extra critical damage, determine whether an attack hits, or handle advantage, disadvantage, or other game rules. Apply those rules at your table.

5. Save and move your collection

Actions and the hit modifier are saved in local storage in the current browser. There is no account sync, so data in one browser or device does not automatically appear on another. Clearing browser site data can remove the collection.

Choose Export to download a JSON backup; the filename field lets you name it. Keep the file somewhere you control. To restore it, choose Import and select a compatible Dice Vault export. Import replaces the current action list after a confirmation prompt, so export the current list first if you want to keep both versions.

This tool calculates dice totals; it is not a rules reference or character sheet. The collection is stored only in your browser, so exported files are the way to move or back up your actions.

Frequently asked questions

Does The Dice Vault upload my saved actions?

No. The app stores the action list and hit modifier in browser local storage. Importing and exporting read or write a file in your browser; the app does not upload those files to an account.

Does a natural 20 automatically double the damage?

No. The d20 control identifies a natural 20 in its result, but it does not change action damage. Follow the critical-hit rules used by your group.

Can I use a different dice progression?

Yes. Enter the base dice and the extra dice per level that fit the progression you need. The roller applies that same extra-dice amount at each level above the base.
